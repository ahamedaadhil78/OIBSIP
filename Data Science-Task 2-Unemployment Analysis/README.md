# Unemployment Analysis with Python

## 📌 Project Overview

This project analyzes unemployment trends in India using Python.

The analysis focuses on regional and monthly unemployment patterns and
examines the changes in unemployment during the COVID-19 period.

## 🎯 Objectives

- Analyze unemployment rates across different regions.
- Study monthly unemployment trends.
- Identify regions with higher average unemployment rates.
- Visualize unemployment trends using charts.
- Compare unemployment before and during the COVID-19 period.
- Understand the relationship between unemployment, employment and labour participation.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

### 1. Data Loading and Inspection
The unemployment dataset was loaded using Pandas and inspected for
its structure, columns and data quality.

### 2. Region-wise Analysis
Average unemployment rates were analyzed for different regions in India.

### 3. Monthly Unemployment Trend
Monthly unemployment rates were visualized using a line chart to
understand changes over time.

### 4. State/Region Comparison
Unemployment trends for selected regions were compared using line charts.

### 5. Top 10 Regions
The regions with the highest average unemployment rates were visualized
using a bar chart.

### 6. Correlation Analysis
A heatmap was used to study the relationship between unemployment rate,
employment rate and labour participation rate.

### 7. COVID-19 Impact
Unemployment levels before and during the COVID-19 period were compared
to understand the change in unemployment.

## 📈 Key Findings

- Unemployment rates changed significantly across different regions.
- A noticeable increase in unemployment was observed during the COVID-19 period.
- Monthly analysis shows significant variations in unemployment over time.
- Regional differences were visible in unemployment rates.
