Email Spam Detection using Machine Learning

📌 Project Overview

This project focuses on detecting spam and legitimate messages using Machine Learning techniques. Text messages are processed and converted into numerical features using TF-IDF. Two Machine Learning algorithms are trained and evaluated to classify messages as Spam or Ham.

This project was developed as part of the Oasis Infobyte Data Science Internship — Task 4.

🎯 Objective

The main objective is to build a Machine Learning classification system that can identify spam messages and distinguish them from legitimate messages.

📂 Dataset

Dataset: SMS Spam Collection

Source: "UCI Machine Learning Repository" (https://archive.ics.uci.edu/dataset/228/sms+spam+collection)

The dataset contains text messages labelled as:

- Ham: Legitimate, non-spam messages.
- Spam: Unwanted or spam messages.

Note: The project title refers to email spam detection, but the dataset used in this implementation contains SMS messages.

⚙️ Project Workflow

1. Import the required Python libraries.
2. Load the dataset using Pandas.
3. Explore the dataset and examine class distribution.
4. Check for missing values and duplicate records.
5. Remove duplicate records.
6. Clean text by converting it to lowercase and removing unwanted characters.
7. Convert text into numerical features using TF-IDF.
8. Encode the target labels:
   - Ham = 0
   - Spam = 1
9. Split the dataset into training and testing sets.
10. Train the Multinomial Naive Bayes model.
11. Train the Logistic Regression model.
12. Evaluate and compare both models.
13. Predict whether a new message is spam or ham.

🤖 Machine Learning Algorithms

1. Multinomial Naive Bayes

A probabilistic classification algorithm commonly used for text classification tasks. It learns patterns from labelled messages and predicts whether a message is spam or ham.

2. Logistic Regression

A classification algorithm that estimates the probability of a message belonging to a particular class.

Both models are evaluated to compare their classification performance.

🔤 TF-IDF Vectorization

TF-IDF stands for Term Frequency–Inverse Document Frequency.

It converts text into numerical features by assigning weights to words based on their frequency and how common they are across the collection of messages.

These numerical features are used as input to the Machine Learning models.

📊 Evaluation Metrics

The models are evaluated using the following metrics:

- Accuracy: Measures the proportion of correct predictions.
- Precision: Measures how many messages predicted as spam are actually spam.
- Recall: Measures how many actual spam messages are correctly identified.
- F1-score: Combines precision and recall into a single metric.
- Confusion Matrix: Shows correct and incorrect classifications.

Recall is particularly important because missed spam messages may be incorrectly classified as legitimate messages.
